前提

Primary Dice（以下「当方」といいます）は、当ウェブサイト （https://primarydice.github.io/ 以下のページ） における個人情報の取り扱いについて、以下のとおり定めます。

収集しない情報

当サイトでは、次のいずれも行っていません。

  • アクセス解析ツール（Google アナリティクスなど）の設置
  • Cookie（クッキー。閲覧者の端末に保存される小さなデータ）の使用
  • 広告の配信、および広告事業者へのデータ提供
  • お名前・住所・電話番号などを入力していただくフォームの設置

したがって、当方が閲覧者の個人情報を当サイト上で直接取得することはありません。

ただし、KAWASE のページにある動画の再生ボタンを押した場合は、下の「動画」に書いたとおり、 YouTube 側で情報が扱われます。

サーバーの記録

当サイトは、GitHub, Inc. が提供する GitHub Pages というサービスを使って公開しています。 当サイトをご覧いただく際、同社のサーバーに、接続元の IP アドレスやブラウザの種類といった 技術的な情報が記録される場合があります。

これは当方が設定しているものではなく、ウェブサイトを公開するうえで同社側で行われる記録です。 当方はこれらの記録を閲覧することも、取得することもできません。詳しくは GitHub 社のプライバシーに関する声明 をご確認ください。

動画

KAWASE の紹介ページには、Google LLC が運営する YouTube の動画を載せています。 この動画は、再生ボタンを押したときに初めて YouTube から読み込みます。 押すまでは、当サイトから YouTube への接続は行いません。

再生ボタンを押すと、YouTube のサーバーに接続元の IP アドレスなどの技術的な情報が送られ、 YouTube が Cookie などを使用する場合があります。読み込みには、Cookie の使用を控えめにする YouTube の「プライバシー強化モード」を使っています。

これらの情報は Google 社のポリシーにもとづいて扱われ、当方が閲覧することも、取得することもできません。詳しくは Google のプライバシーポリシー をご確認ください。

お問い合わせ

メールでお問い合わせをいただいた場合、そのメールに含まれるメールアドレスと本文を、 お返事および記録のために保管します。次の目的以外には利用しません。

  • お問い合わせへの回答
  • 不具合のご報告に対する調査と修正

ご本人の同意がある場合、または法令にもとづき開示を求められた場合を除き、 第三者に提供することはありません。

外部リンク

当サイトには、他社が運営するサイトへのリンクが含まれています。 リンク先での個人情報の取り扱いについて、当方は責任を負いかねます。 リンク先各社のプライバシーポリシーをご確認ください。

内容の変更

本ポリシーの内容は、必要に応じて変更することがあります。 変更した場合は、このページの最終更新日を書き換えてお知らせします。
