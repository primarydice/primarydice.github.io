# Primary Dice 公式サイト

会社（個人事業 Primary Dice）の公式サイトです。**2026-09-02 に公開しました。**

- 公開URL: https://primarydice.github.io/
- リポジトリ: `primarydice/primarydice.github.io`（Public）

アプリはまだ Google Play に出していないため、各アプリのページには
「未発売」の刻印が入っています。発売したときの差し替え手順は第4章にあります。

## 1. パソコンで表示を確認する

> ### ⚠ `index.html` をダブルクリックしても、正しく表示されません
>
> 真っ黒な背景も、レイアウトも、画像も出ません。壊れたように見えますが**故障ではありません**。
>
> このサイトは、ページの中で画像やデザインの置き場所を `/assets/...` という
> 「サイトの入口からの住所」で書いています。公開後の `https://primarydice.github.io/` では
> これが正しく働きますが、ファイルを直接開いた場合は入口が存在しないため、
> パソコンは置き場所を見つけられません。
>
> **確認するときは、必ず下の手順でサーバーを起動してください。**

このフォルダで、次のファイルを右クリック →「PowerShell で実行」でも動きますが、
確実なのはコマンドから実行する方法です。

```
powershell -ExecutionPolicy Bypass -File "C:\Users\daisuke\クロード\会社サイト\serve.ps1"
```

起動したらブラウザで **http://localhost:8140/** を開いてください。
このウィンドウは開いたままにしておきます（閉じるとサーバーが止まります）。
止めるときは `Ctrl` + `C` です。

> `serve.ps1` は確認用です。実際の公開は GitHub Pages が行うので、
> このファイルがアップロードされても使われません。

### デザインの考え方

ロゴは平面の記号ではなく、面取りと光沢を持つ**金属のバッジ**です。
そこでサイト全体を、機械に取り付けられた「銘板（めいばん）」として作っています。

- **区切り線は引くのではなく彫る。** 暗い線のすぐ下に明るい線を置くと、削られた溝に見えます
- **和文の見出しは明朝体。** 日本の製品カタログの作法（見出し＝明朝／本文＝ゴシック）です
- **左に項目名、右に内容。** 機械の銘板や製品仕様書と同じ並べ方です
- **光るのは読み込み直後の一度だけ。** ロゴの上を光がすべります。金属は自分から点滅しません

> **色を足さないこと。** ロゴが無彩色なので、青やアクセントカラーを1色でも入れると
> ブランドが崩れます。濃淡だけで組んでください。

> **このフォルダは git 管理外です。** 大きく作り変えるときは、先にフォルダごと複製して
> 控えを取ってください。
>
> ⚠️ 2026-08-20 にこのフォルダは OneDrive の外へ移しました。
> **クラウドの自動バックアップも、バージョン履歴からの復元もありません。**
> 控えは自分で取ること。

## 3. 画像を作り直す

素材を入れ替えたときは、次の2つを実行してください。何度実行しても大丈夫です。

```
powershell -ExecutionPolicy Bypass -File tools\make-logo.ps1
```

`会社ロゴ.png` から、透過したロゴ・マーク・ファビコン・SNS共有用画像を作ります。
（元の `会社ロゴ.png` は変更しません）

```
powershell -ExecutionPolicy Bypass -File tools\copy-assets.ps1
```

各アプリの `store-assets` フォルダから、アイコンとスクリーンショットを
サイト用の大きさに縮めてコピーします。

> **PowerShell のファイルを編集したときの注意**
> `.ps1` ファイルを別のエディタで保存し直すと、日本語が文字化けして
> エラーになることがあります。その場合は「UTF-8（BOM付き）」で保存してください。

## 4. アプリを公開したら差し替えること

各アプリの紹介ページの上のほうに、いま次の「刻印」が入っています。

```html
<p style="margin-top:26px"><span class="stamp">未発売</span></p>
```

Google Play で公開したら、この1行を**ストアへのボタンに差し替えて**ください。

```html
<p style="margin-top:26px"><a class="btn" href="ここにストアのURL">Google Play で入手</a></p>
```

あわせて、次の場所も直します。

| 場所 | やること |
|---|---|
| 各アプリページの「公開状況」「注記」 | 「まだ Google Play に出していません」の囲みを削除する |
| `index.html` の「製品」の説明文 | 「4つは作り終えて、Google Play での公開を準備しています。」を書き換える |
| `index.html` の「記録」 | 公開した日を1行足す |
| `sitemap.xml` | `<lastmod>` の日付を更新した日に書き換える |

> **押せないボタンを置かないこと。** リンク先が無いボタンは、
> 信用を作るどころか逆効果になります。公開してから差し替えてください。

## 5. 公開の手順（実施済み。作り直すときの参考）

1. GitHub で `primarydice` 組織に、**`primarydice.github.io`** という名前で
   新しいリポジトリを作る（Public）
   - この名前にすると、URL が `https://primarydice.github.io/` になります。
     ほかの名前だと `https://primarydice.github.io/リポジトリ名/` と余計な文字が付きます
2. このフォルダの中身を push する
3. リポジトリの Settings → Pages で、公開するブランチを指定する
4. 数分待って `https://primarydice.github.io/` を開き、全ページの表示を確認する
5. [Google Search Console](https://search.google.com/search-console) にサイトを登録する
   - 検索結果に何回出たか、どんな言葉で探されたかが分かる無料のツールです
   - 訪問者を追跡するものではないので、プライバシーポリシーを増やす必要はありません
6. Play Console の各アプリの「ウェブサイト」欄に、対応するページの URL を設定する

### 公開してはいけないもの

このリポジトリは **公開（Public）** になります。
署名キー（`release-keys`）やパスワードなど、人に見られて困るファイルは絶対に置かないでください。

`計画.md` と `他社AIへの質問文.md` は制作時のメモなので、公開対象から外しています
（`.gitignore` に書いてあります）。

## 6. 独自ドメインに移すとき

`primarydice.jp` などを取得した場合は、作り直す必要はありません。

1. このフォルダに `CNAME` という名前のファイルを作り、中にドメイン名だけを書く
2. ドメイン会社の管理画面で、GitHub Pages 向けの設定（DNS レコード）を行う
3. リポジトリの Settings → Pages でドメインを入力し、HTTPS を有効にする

そのあと、各ページの `<link rel="canonical">` と `og:url`、`sitemap.xml`、
`robots.txt` に書いてある `https://primarydice.github.io/` を、
新しいドメインに置き換えてください。
